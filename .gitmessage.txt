# ────────────────────────────────────────────────────────────
# 提交信息模板  |  格式：<type>(<scope>): <subject>
# ────────────────────────────────────────────────────────────
# type 可选：
#   feat     新增能力（加源、加解析）
#   fix      修复（失效站点替换、脚本报错）
#   chore    自动更新 / 杂项（GitHub Actions 提交用这个）
#   docs     文档改动
#   refactor 重构不改变行为
#   perf     性能优化
# ────────────────────────────────────────────────────────────
# scope 可选：source / script / workflow / docs
#
# 示例：
#   feat(source): 追加 XX 采集源
#   fix(script): 修复 JSONC 注释解析
#   chore: auto update tvbox source [skip ci]
#
# 规则：subject 用中文或英文均可，不超过 50 字，结尾不加句号
# ────────────────────────────────────────────────────────────

<type>(<scope>): <subject>
